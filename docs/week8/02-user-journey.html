FLOW AT A GLANCE

한눈 흐름 — 화면 상태 기계

사용자 입장에서 대기열은 화면 4개짜리 상태 기계입니다: 상품 → 대기실 → (내 차례) → 주문. 대기실에서만 시간이 흐르고, 나머지는 순간 전환입니다.
